Week 01 Assessment Solutions & Working Guide
Q1 - AI → ML → Deep Learning → Generative AI → AI Agents
A - Answer

Artificial Intelligence (AI): The broad field of computer science concerned with creating systems that can perform tasks associated with human intelligence, such as reasoning, perception, learning, decision-making, and problem-solving.

Machine Learning (ML): A subset of AI in which systems learn patterns from data and use those patterns to make predictions, classifications, or decisions rather than relying only on explicitly programmed rules.

Deep Learning (DL): A subset of machine learning that uses multi-layered neural networks to learn increasingly complex patterns and representations from data.

Generative AI (GenAI): AI systems designed to generate new content such as text, images, audio, video, or code based on patterns learned from training data.

AI Agent: A system that uses one or more AI models to pursue a goal by interpreting information, deciding what actions to take, and potentially using external tools, applications, or data sources.

Conceptual Relationship
Artificial Intelligence (AI)
│
└── Machine Learning (ML)
    │
    └── Deep Learning (DL)
        │
        └── Many modern Generative AI systems


AI agents are better understood as a system or application layer rather than simply another nested category. An agent may use ML, deep-learning, or generative-AI models together with tools, data, memory, and action mechanisms.

Everyday Examples

AI: A rule-based expert system that assists with technical diagnosis.

ML: An email spam classifier trained using examples of spam and legitimate messages.

DL: A neural-network-based image-recognition system that identifies objects in photographs.

GenAI: ChatGPT generating a written explanation from a user's prompt.

AI Agent: A software system that receives a task, retrieves information, uses available tools, performs actions, and reports the result.

E - Evidence

The AI → ML → DL relationship is consistent with standard educational and technical descriptions from sources such as IBM and established AI textbooks. Modern generative-AI systems commonly use deep-learning architectures, while AI agents generally combine an AI model with additional system components that allow the system to interact with tools or an environment.

V - Verification

I compared the definitions and relationships between AI, ML, DL, GenAI, and AI agents using multiple technical and educational sources. I also checked whether the hierarchy accurately represented the relationship between these concepts.

One important clarification from the verification process is that AI agents should not necessarily be represented as a strict subset of deep learning or generative AI. An agent is better described by how a system uses models, tools, information, and actions to accomplish a goal.

R - Reflection

Understanding the relationship between these terms helps avoid treating all AI technologies as the same thing. For my VLSI/DFT learning, this distinction is useful because AI may refer to the overall field, ML/DL may describe the underlying learning techniques, GenAI may assist with content and code generation, and an agent may combine these capabilities into a workflow.
