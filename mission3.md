**Mission 3 — Is it really AI?**
Objective: Distinguish traditional software from AI-based systems.
Step 1: Complete the classification table
System	Classification	Reason
Calculator	Traditional software	Executes explicitly programmed arithmetic operations.
Temperature warning rule	Rule-based software	Compares the temperature with a predefined threshold.
Spam filter	ML-based AI, commonly	Learns patterns associated with spam; some filters also use rules.
Document summariser	Generative AI, if it uses an LLM	Generates a shorter version of the source document. Other summarisation systems may use different methods.
Traffic ETA prediction	ML-based AI, commonly	Can use historical and current traffic data to predict travel time.
Step 2: Explain one easy classification
Easy example — Calculator: A basic calculator uses programmed arithmetic operations. It does not need to learn from examples to calculate \(25+35=60\).
Step 3: Explain one difficult classification
Difficult example — Spam filter: A spam filter may use manually written rules, machine learning, or a combination of both. We cannot classify every spam filter as AI without knowing how it is implemented.
Step 4: Give your own example
Example — Handwritten digit recognition: A machine-learning model trained on images of handwritten digits can predict which digit appears in a new image.
This is ML-based AI because the model learns patterns from training examples.
Submission: The table and three short explanations.
