Step 3: Answer the rule-based question
Question: Could a simple rule-based program produce similar behaviour?
Answer: Yes, a rule-based program could recommend videos using fixed rules, such as recommending videos from a selected category. However, a machine-learning recommendation system can learn patterns from user interactions and use multiple signals to personalise suggestions. A simple rule-based system may be sufficient for basic recommendations, but it may not provide the same level of personalisation.
Step 4: Write your conclusion
AI is used in many everyday technologies, but not every intelligent-looking feature uses AI. Traditional software follows explicitly programmed rules, whereas machine-learning systems learn patterns from data. The implementation must be checked before claiming that a particular feature uses AI.
