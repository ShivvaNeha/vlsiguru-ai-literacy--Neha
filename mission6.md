**Mission 6 — Chatbot or agent?**
Objective: Understand the components used in AI applications.
Step 1: Learn five terms
Term	Simple explanation	Example
LLM	A language model that processes and generates text.	A model answering questions.
AI application	A complete software product that uses one or more AI capabilities.	An AI study assistant.
RAG	Retrieval-Augmented Generation; retrieves relevant information to help a model answer.	A chatbot answering questions from course PDFs.
Tool-using assistant	An assistant that can invoke tools or services.	An assistant that runs a calculation using a tool.
Agent	A system that uses a model and other components to pursue a goal through multiple steps.	A system that searches documentation, analyses results and prepares a report.
An agent may use tools and retrieval, but not every chatbot or tool-using assistant is necessarily an agent.
Step 2: Draw a workflow
1. User
Asks a question

2. AI model
Interprets the request

3. Retrieval or tool
Finds information or performs an operation

4. AI model
Uses the result to prepare a response

5. User
Receives the answer or completed action


This is a simplified workflow. Depending on the application, the model may call multiple tools, repeat steps, or respond without calling a tool.
Step 3: Give an everyday agent example
An AI travel-planning agent could receive a request for a trip, search for available transport and accommodation, compare the options, and prepare an itinerary. Any actual bookings should require appropriate user authorisation.
