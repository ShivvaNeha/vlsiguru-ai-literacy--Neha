**Mission 2 — AI, ML, Deep Learning and Generative AI**
Objective: Understand four important terms and how they relate.
Step 1: Write the four definitions
1. Artificial Intelligence (AI)
AI is a broad field of computer science that develops systems capable of performing tasks associated with intelligence, such as reasoning, recognising patterns, planning and making decisions.
Example: An AI assistant answering questions.
2. Machine Learning (ML)
ML is a branch of AI in which computers learn patterns from data to make predictions or decisions instead of relying only on manually written rules.
Example: An email spam filter trained on examples of spam and legitimate emails.
3. Deep Learning (DL)
Deep learning is a type of machine learning that uses neural networks with multiple layers to learn complex patterns from data.
Example: A deep-learning model recognising objects in images.
4. Generative AI (GenAI)
Generative AI creates new content, such as text, images, audio or code, based on patterns learned from training data.
Example: An AI assistant generating a Python program from a text prompt.
